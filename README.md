# 八班风云 · 课间对决

一款**校园题材的原创卡牌对战网页游戏**。选一位同学出战，用他/她自己的绝活卡池打一场课间十分钟的对决。
纯静态、零依赖、零构建工具：**原生 ES Module + 手写 CSS + 手写 SVG 贴图**。

> 人物与桥段全部来自同学之间的玩笑改编，属校内娱乐向作品；调侃一律往热闹可爱的方向走，不做人身攻击。
> 游戏里的"受伤"都是夸张的舞台效果（创可贴、请假条、臭气云），不涉及任何写实的伤害描写。

---

## 怎么玩

**双击 `index.html`** 就行。它是**一个完全自包含的文件**（1.4 MB）：源码、样式、数据、122 张 SVG 贴图全部内联在里面，
不需要服务器、不需要联网、不需要装任何东西。

### 三个玩法

开始界面顶部是三张模式卡片，随时能切：

| 模式 | 是什么 |
| --- | --- |
| **新手教程** | 13 步手把手：认成绩条 → 出打击牌 → 精力用尽 → 结束回合 → 抽牌 → 助攻/防御 → 攒气势 → **放大招** → 认识状态 → 状态在铃响时结算 → 数对手手牌 → 收尾一击 → 通关。每步高亮要点元素，等你真做了才继续，也能跳过。 |
| **剧情模式** | 3 关 6 场。第 1 关教出牌与精力（对手 6 分、牌堆削到 10 张）；第 2 关教状态结算与护盾；第 3 关是班际挑战（最后一战对手 15 分、完整牌库）。通关自动解锁下一关，进度存本机。 |
| **无尽模式** | 自己挑人打。连胜 2/4/6/8/10 场时对手逐级变强（起始成绩 +1~+4、额外抽牌、起始气势），最高连胜记在本机。 |

### 30 秒看懂规则

1. **成绩**既是血条也是进度条：开局 10 分，**涨到 20 直接赢**，**掉到 0 直接输**。既能"卷赢"，也能被打崩。
2. 一个回合：上课铃 → 结算残留状态 → 抽 2 张 → 精力回满 → 气势 +1 → 自由出牌 → 下课铃（结算臭气/干儿子等）。
3. **精力**决定这回合能出几张牌；**气势**每回合 +1，攒到 3 点能放**大招**（一局一次）。
4. 卡牌分四类：`打击` / `套路` / `助攻` / `大招`；每人 18 张专属 + 12 张公共 = 30 张牌堆。
5. 后手开局多发 1 张牌（先手补偿），实测先后手胜率接近五五开。

**卡池随时能查**：选人页最下面内嵌完整图鉴（4 角色 + 公共牌页签，卡面就是结算规则）；
选人卡片右下角「看卡池 ▸」、对局中右侧「卡池」按钮都能弹出图鉴。

**手机**：竖屏也能打完一局，手牌横向滑动，操作按钮贴底。

**出牌方式（手机 / 电脑都一样）**：**点一下选中，再点一下打出**。
第一次点牌会把它抬起来、顶上出现「再点一下出招」，并把卡面说明贴到屏幕上；第二次点同一张才真的打出去。
点另一张牌只会换选中目标，点空白处取消选中。这样手机上手指不会挡住卡面，也不会误出牌。

**快捷键**：`1-8` 出牌 · `空格/回车` 结束回合 · `Esc` 关弹窗。

## 想改东西？

卡池、剧情、教程步骤、配色**都在 `data/` 的 JSON 里**，不用碰代码：

| 文件 | 改它能得到什么 |
| --- | --- |
| `data/characters.json` | 角色数值、72 张专属牌、状态层数上限、先后手补偿 |
| `data/common.json` | 12 张公共牌 |
| `data/story.json` | 三个剧情关的台词、对手、起始成绩、简化牌堆 |
| `data/modes.json` | 教程 13 步脚本、三模式文案、无尽难度曲线 |
| `data/ui-tokens.json` | 配色 / 字号 / 圆角 / 动画时长 |
| `src/embedded-data.js` | 上面这些 JSON 的**内联快照**（离线/双击版靠它读数据） |
| `art/art-bundle.js` | 122 张贴图的**贴图包**（路径 → data URI） |

改完执行一次打包，让 `index.html` 用上新数据：

```powershell
node tools/build.js
```

它会自动检查依赖有没有漏（漏一个模块就会在页面上报错），然后重新生成 `index.html`。
想调试代码（改 `src/` 里的逻辑）就用任意静态服务器打开 `src/index.html`，改完刷新即可。

**目录结构**

```
index.html               ← 成品：单文件，双击即玩
README.md                ← 这份说明
data/                    ← 卡池 / 剧情 / 教程 / 配色（JSON）
art/art-bundle.js        ← 122 张贴图打包（含 84 张卡牌插画）
src/
  index.html             ← 开发版入口（外链源码）
  engine.js              ← 对局引擎：回合流程、效果解释器、胜负判定
  ai.js                  ← 电脑对手（启发式 + 难度 + 教学放水）
  view.js                ← 界面渲染与出牌演出编排
  tutorial.js            ← 教程：读脚本 + 解说层 + 推进
  tutorial-auto.js       ← 教程自动演示（?tutauto=1，自测用）
  story.js               ← 剧情推进 + 本机进度
  utils.js               ← 贴图、卡面 DOM、设计 token 注入、常量表
  audio.js               ← Web Audio 合成音效（不用音频文件）
  embedded-data.js       ← 数据快照（自动生成）
  main.js                ← 入口：模式选择、选人、开打、结算
styles/                  ← 6 个样式表（含卡面 v2 与出牌演出）
tools/
  build.js               ← 打包：node tools/build.js（会自动同步数据与贴图）
  sync-assets.js         ← 数据快照 + 贴图包（由 build.js 自动调用，一般不用单独跑）
  check-art.js           ← 贴图体检：逐张验合法性、找空图、查缺失引用
  test-click.js          ← 出牌交互自测（点一下选中 / 再点一下打出）
docs/design.md           ← 玩法/UI/卡面/数值的完整设计说明（合并版）
```

## 一些小提示

- 网页上传到 GitHub 有"一次最多 100 个文件"的限制，本项目 **32 个文件**，直接全选拖进去即可。
- 想发到静态托管，只需要 `index.html` 一个文件就能跑（其他都是可选的源码与素材）。
- 调试用链接参数：`?mode=tutorial|story|endless`、`?step=8`（跳到教程第 8 步）、`?auto=1`（打开即开打）、
  `?newgame=1`（清掉本机进度）、`?speed=0.2`（五倍速）、`?diag=1`（把关键状态打到屏幕上）。
- 想自己检查素材和交互，两条命令就够：
  ```powershell
  node tools/check-art.js     # 122 张贴图逐张验：合法 / 非空 / 无缺失
  node tools/test-click.js    # 自动点两次牌并截图，核对"点一下选中、再点一下打出"
  ```
